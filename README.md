**AI 视频全流程工业化生产规范与工具链（v2.0）** ｜ Claude Code / Agent Skill

> **定位**：面向 **AI 实拍风短片、品牌宣传片 / TVC、叙事短片、MG 动画** 的全链路生产工作流。
> 它解决的不是「单张图或单条视频好不好看」，而是工业化交付最核心的五个目标：**全片一致性、分镜可预期、资产零散落、返工低成本、成片硬验收**。

## 核心生产目标与痛点解决

| 传统 AI 视频痛点 | 根因 | 本方案实现的工程目标 |
|---|---|---|
| **越往后拍越飘，换镜就换脸/换景** | 没有可继承的全局约束，提示词各自为战 | **《项目总纲》+ 提示词继承块**：锁定视觉基准、焦段、光位、空间方位与左右关系，`提示词关卡.py` 强制校验继承 |
| **分镜节奏散乱，台词与画面各说各话** | 缺乏量化节奏红线与一镜一主角约束 | **分镜与节奏双关卡**：`分镜关卡.py`（八列填满 + 一镜一主角）与 `节奏关卡.py` 守住台词密度与换镜节奏 |
| **参考图与提示词管理混乱、重复传图浪费图位** | 网页改字、本地找图、提交提示词三套体系脱节 | **可编辑分镜数据看板**：网页改字/拖图直通硬盘，删图自动归档 `_弃用/`，打包提交按 MD5 自动去重映射 `@图1~@图N` |
| **一条成片有 2 个镜头瑕疵，整段重生成烧光积分** | 缺少精准质检定位与低成本局部补拍机制 | **质检补拍闭环 + 2 帧安全剪辑**：只把拍板要改的镜头进补拍看板（原帧作底帧），成片按时间点预留 1~2 帧安全余量只切画面、不重剪音频 |
| **改图把背景重画、拼接断层、成品漏检** | 靠肉眼经验抽查，没有强制拦截门禁 | **唯一入口关卡链**：`取帧.py` → `改图.py` → `比对.py` → `收口.py` → `验收视频.py`，自检不过零写入 |

## 全流程工业化闭环

```
[0] 需求与总纲定调 ── 收集主题/时长/画幅/主角/音色/风格参考图，立《项目总纲》十项基准
  ↓
[1] 剧本与分镜关卡 ── 分镜表八列完备 + 一镜一主角 + 节奏硬线校验（分镜关卡.py / 节奏关卡.py）
  ↓
[2] 可编辑分镜看板 ── 生成 HTML 看板 + 启动本地同步服务（scripts/start_editable_dashboard.py）
  │                    ├─ 每镜 10 字以内简写 + 四段可编辑文本 + 一键复制融合提示词
  │                    └─ 拖图直写 02_分镜参考帧/XX_简写/，删图自动进 _弃用/
  ↓
[3] 参考帧与修图关卡 ─ 扫全镜取「元素最全帧」→ 帧问题清单销项 → 改图.py / 比对.py / 收口.py
  ↓
[4] 逐镜/分块生成 ── 按 MD5 自动去重 @图1~@图N → 报积分等确认 → 720p 默认生成（发镜头.py）
  ↓
[5] 拍后质检与补拍 ── 自动下载抽帧出「质检结果报告」→ 导演拍板问题镜头进「补充镜头看板」低成本补拍
  ↓
[6] 2 帧安全剪辑与验收 ─ 按质检时间点前后预留 1~2 帧安全余量「只切画面」保留原音频 → 验收视频.py 交付
```

---

## 七条核心铁律

1. **报积分 → 用户点头 → 才动手**：每步生成前算清消耗与余额，获批后提交。
2. **改图走唯一入口 `tools/改图.py`，改完必跑 `tools/比对.py`**：禁止绕过元素声明与参考图核验。
3. **打回重做只走「帧改帧 + 局部重生成」**：只认成片帧或同风格元素图，严禁整段推翻重跑。
4. **每条规则都要有出处，每张成品都要对定稿**：不凭记忆写否定词，不以旧脚本代替定稿图。
5. **截帧即立「帧问题清单」**：清单未销完不许定稿，也不把本应查定稿的问题甩给用户。
6. **定底稿前扫全整个镜头，取「元素最全」那一帧**：`tools/取帧.py` 出接片图，人眼定帧。
7. **成品只能由 `tools/收口.py` 与 `tools/验收视频.py` 写出**：自检不过，成品文件一个字节都不会落盘。

## 可编辑分镜数据看板与 2 帧安全剪辑

完整规范见 [`AI导演看板.md`](AI导演看板.md) 与 [`SKILL.md` §0.65](SKILL.md)：

1. **拍前「可编辑分镜看板」+ 本地同步服务（`scripts/start_editable_dashboard.py`）**：
   - 每镜标题规范 `Shot XX · <10字以内简写>`，与 `02_分镜参考帧/XX_<简写>/` 目录 100% 一一对应；
   - 每镜卡片具备 4 段可编辑文本（`🎬 镜头内容简述` / `🖼️ 图片提示词` / `🎥 详细视频提示词` / `🎵 音效与 BGM`）及右下角 `📋 一键复制整镜融合提示词`；
   - 浏览器拖图直接写盘，点击 `×` 删除自动移入 `XX_<简写>/_弃用/`（防误删、可找回），`Cmd+S` 同步写回 HTML 与 `storyboard_manifest.json`；
   - 本地按镜全量存放参考图，提交生成前脚本按文件 MD5 指纹自动去重并统一映射为 `@图1 ~ @图N`。
2. **拍后质检 → 补拍看板 → 2 帧安全余量自动剪辑**：
   - 首轮成片自动下载并抽帧生成质检报告，精确记录每镜起止时间点与帧号；
   - 导演拍板只改的问题镜头拆入「补充镜头看板」，以原视频截帧为底帧进行短片低成本补拍；
   - 补拍确认后，按起止时间点前后预留 **1～2 帧安全余量**，仅替换视频画面轨道、完整保留原片音频与节奏，输出 `*_FINAL_2帧安全版.mp4`。

## 全套关卡与流程工具（tools/）

| 脚本 | 阶段 | 核心职责与拦截能力 |
|---|---|---|
| `分镜关卡.py` | 分镜定稿 | 强制校验分镜表八列完备 + 每镜唯一主角（关卡 K-1） |
| `提示词关卡.py` | 提示词编写 | 校验《项目总纲》继承块（视觉基准/镜头参数/空间方位/画面左右）未丢失 |
| `节奏关卡.py` | 台词与时长 | 校验台词密度、单镜时长、换镜频率与屏幕字硬线 |
| `建任务表.py` | 批量调度 | 生成标准化分镜任务清单与批次台账 |
| `预览拼图.py` | 人工审图 | 输出多镜参考帧拼接预览图，便于快速人眼巡检 |
| `取帧.py` | 底稿选取 | 对整段视频抽帧输出接片图，防止截到信息不全的帧 |
| `改图.py` | 参考帧精修 | 改图唯一入口：强制元素声明与参考图文件存在性校验 |
| `比对.py` | 改后/生前核验 | 量化背景区色差矩阵，拦截「背景被重画、画风漂移」的废帧 |
| `收口.py` | 成品图交付 | 掩码越界/漏改两查 + 强制分块看图自检，过关才落盘 |
| `发镜头.py` | 视频生成提交 | 标准化提交视频生成任务并记录台账 |
| `验收视频.py` | 成片拼接交付 | 切点闭环校验 + 实测数帧核验，确保成片零错帧、零断层 |

> 所有脚本默认以 **dry-run** 安全模式运行，确认无误后再加 `--go` / `--成品` 执行落盘或提交。

## 环境依赖

```bash
pip install pillow opencv-python numpy
```

- **视频/图像生成**：即梦 CLI（`dreamina`）或对应多媒体生成工作流
- **多模态视觉分析**：视觉理解模型（如 Qwen-VL，用于风格拆解与拍后抽帧质检）
- **音视频处理**：`ffmpeg` / `ffprobe`
